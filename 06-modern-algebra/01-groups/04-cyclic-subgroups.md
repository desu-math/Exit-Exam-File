# Cyclic Subgroups

Let me introduces cyclic subgroups using powers of an element in a group. Let’s focus on the main idea, notation, and examples.

## Powers of an element

The notes begin with a group G and an element a ∈ G. For any integer n, they define:

aⁿ = a multiplied by itself n times.
a⁰ = e, where e is the identity element.
a⁻ⁿ = a⁻¹ multiplied by itself n times.

Here, multiplication means the group operation, which does not necessarily have to be ordinary multiplication.

---

Example: Consider the group (Z₁₂, ⊕₁₂), where the operation is addition modulo 12.

The identity is 0. Repeatedly adding 3 gives:

3¹ = 3
3² = 3 ⊕ 3 = 6
3³ = 3 ⊕ 3 ⊕ 3 = 9
3⁴ = 3 ⊕ 3 ⊕ 3 ⊕ 3 = 0

Notice that the notation uses powers, but the operation is actually addition modulo 12.

The important observation is that repeatedly applying the operation to an element can eventually produce the identity.

---

## Definition of a cyclic subgroup

If G is a group and a ∈ G, then

H = {aⁿ : n ∈ Z}

is a subgroup of G containing a.

This subgroup is called the cyclic subgroup generated by a.

The notation is:

H = ⟨a⟩

---

### What does this mean?

To find ⟨a⟩, collect all the integer powers of a, including:

Positive powers: a, a², a³, ...
The zeroth power: e
Negative powers: a⁻¹, a⁻², ...

The set of all distinct elements obtained is the cyclic subgroup generated by a.

In a finite group, elements eventually repeat, so the subgroup contains only finitely many distinct elements.

---

Example 1: The group Z₄

considers the group (Z₄, ⊕₄), whose elements are:

Z₄ = {0, 1, 2, 3}

The operation is addition modulo 4.

Generate the group using 1

Repeatedly add 1 modulo 4:

1¹ = 1
1² = 1 + 1 = 2
1³ = 1 + 1 + 1 = 3
1⁴ = 1 + 1 + 1 + 1 = 0

We have now obtained every element of Z₄.

Therefore,

⟨1⟩ = {0, 1, 2, 3} = Z₄

---

Generate the group using 3

Now repeatedly add 3 modulo 4:

3¹ = 3
3² = 3 + 3 = 6 ≡ 2 (mod 4)
3³ = 3 + 3 + 3 = 9 ≡ 1 (mod 4)
3⁴ = 3 + 3 + 3 + 3 = 12 ≡ 0 (mod 4)

Again, we obtain every element.

Therefore,

⟨3⟩ = {0, 1, 2, 3} = Z₄

Conclusion: Z₄ = ⟨1⟩ = ⟨3⟩

Thus, Z₄ is a cyclic group.

---

Key lesson: Different elements can generate the same cyclic group.

---

Example 2: The Klein four group

Your PDF considers the Klein four group:

V = {e, a, b, c}

Its elements satisfy:

a² = e, b² = e, c² = e

Let's generate a subgroup using a.

Since a² = e, the powers repeat:

a¹ = a
a² = e
a³ = a
a⁴ = e

Therefore,

⟨a⟩ = {e, a}

Similarly,

⟨b⟩ = {e, b}

⟨c⟩ = {e, c}

Each element generates a subgroup containing only itself and the identity.

But the whole group contains four elements:

V = {e, a, b, c}

No single element generates all four elements. Therefore, as the PDF concludes, the Klein four group is not cyclic.

---

## When is a group cyclic?

An element a is a generator of G if

G = ⟨a⟩

A group G is called cyclic if there exists at least one element a ∈ G such that

G = ⟨a⟩

---

In simple terms:

Cyclic subgroup: The subgroup generated by one particular element.
Cyclic group: A group in which one element can generate the entire group.

For example, Z₄ is cyclic because ⟨1⟩ = Z₄. The Klein four group is not cyclic because none of its elements generates the entire group.
