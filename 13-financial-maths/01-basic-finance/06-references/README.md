# References — Chapter 1: Basic Finance Concepts

This folder contains the lecture materials and reference books used to study and prepare the notes for Chapter 1.

These resources support the development of the theory, algorithms, and worked examples presented in this chapter.

## 1. Primary Learning Material

* **Lecture Note:** Financial Mathematics (Math 4313), prepared by Tamirat T. Dufera (PhD), Department of Applied Mathematics, ASTU, October 8, 2025.

## 2. Reference Books

The following books were consulted to support understanding of the chapter topics:

1. *An Introduction to Mathematical Finance with Applications: Understanding and Building Financial Intuition* — Arlie O. Pette.
2. *An Introduction to Financial Mathematics: Option Valuation* — CRC Press, 2019.
3. *An Introduction to Financial Engineering* — Springer, 2003.

## 3. How These References Were Used

The lecture note serves as the primary source for the chapter's topics and organization. The reference books provide additional explanations and support for understanding the mathematical concepts.

The chapter is organized into five topics:

1. Interest
2. Inflation
3. Annuities
4. Bonds
5. Internal Rate of Return (IRR)

Each topic includes theoretical explanations and step-by-step computational algorithms.
