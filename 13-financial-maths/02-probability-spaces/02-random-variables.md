## 1. Introduction

In the first part of this chapter, we studied probability spaces, sigma-fields, probability measures, conditional probability, and independence.

In this part, we introduce random variables and probability distributions.

A random variable transforms the outcomes of a random experiment into numerical values. This allows us to study random phenomena mathematically using functions, probabilities, and distributions.

For example, instead of studying every possible detail of customers entering a bank, we may define a random variable representing the number of customers arriving within an hour.

We can then investigate questions such as:

- What is the probability that exactly 10 customers arrive?
- What is the probability that fewer than 5 customers arrive?
- What is the probability that more than 20 customers arrive?

To answer such questions, we need to understand random variables and their probability distributions.

## 3. Random Variables

### 3.1 Definition

Let (Ω, F, P) be a probability space.

A random variable is a function:

**X: Ω → R**

such that, for every interval J in R:

**{ω ∈ Ω : X(ω) ∈ J} ∈ F.**

This condition means that the inverse image of every interval under X must be an event in the sigma-field F.

In simpler terms, a random variable assigns a real number to every possible outcome of a random experiment.

### 3.2 Understanding Random Variables

Consider an experiment in which a fair coin is tossed twice.

The sample space is:

Ω = {HH, HT, TH, TT}

Define X as the number of heads obtained.

| Outcome | X(ω) |
|---|---:|
| HH | 2 |
| HT | 1 |
| TH | 1 |
| TT | 0 |

Therefore, the random variable assigns:

- X(HH) = 2
- X(HT) = 1
- X(TH) = 1
- X(TT) = 0

The range of X is:

X(Ω) = {0, 1, 2}.

Notice that the outcomes themselves are not necessarily numerical. The random variable transforms them into numerical values.

### 3.3 Why Are Random Variables Important?

Random variables allow us to represent uncertain quantities mathematically.

For example:

- Number of customers arriving at a bank.
- Daily return on an investment.
- Number of loan defaults.
- Time required to complete a financial transaction.
- Amount of money spent by a randomly selected customer.

By assigning numerical values to outcomes, we can calculate probabilities and study the behavior of these quantities.

### 3.4 The Measurability Condition

The condition:

**{X ∈ J} ∈ F**

is called the measurability condition.

Recall that F is a sigma-field containing the events to which probabilities can be assigned.

Therefore, the measurability condition ensures that events generated by the random variable belong to F.

For example, using the two-coin experiment, let:

X = Number of heads.

Choose the interval:

J = [1, 2].

Then:

{X ∈ [1, 2]} = {HH, HT, TH}.

This set must belong to F so that we can calculate:

P(X ∈ [1, 2]).

**Main idea:** A random variable must generate measurable events so that their probabilities are well-defined.

## 4. Conditions for a Function to Be a Random Variable

A real-valued function X on a probability space (Ω, F, P) is a random variable if and only if any one of the following conditions holds for every t ∈ R:

1. {X ≤ t} ∈ F.
2. {X < t} ∈ F.
3. {X ≥ t} ∈ F.
4. {X > t} ∈ F.

These conditions are equivalent because sigma-fields are closed under complements and countable unions.

### Example

Consider again:

Ω = {HH, HT, TH, TT}

Let X be the number of heads.

For t = 1:

{X ≤ 1} = {HT, TH, TT}.

For t = 0:

{X ≤ 0} = {TT}.

For X to be a random variable, these sets must belong to F for every real value of t.

### Why Are These Conditions Useful?

Instead of checking the inverse image of every possible interval, we can prove that one of the four conditions holds for every real t.

This provides a convenient method for proving that a function is a random variable.

## 5. Indicator Functions

### 5.1 Definition

The indicator function of a subset A ⊆ Ω is defined as:

**1_A(ω) =**

- 1, if ω ∈ A.
- 0, if ω ∉ A.

The indicator function tells us whether a particular outcome belongs to a given set.

### 5.2 Example

Consider:

Ω = {HH, HT, TH, TT}

Let:

A = {HH, HT}.

The indicator function is:

| Outcome | 1_A(ω) |
|---|---:|
| HH | 1 |
| HT | 1 |
| TH | 0 |
| TT | 0 |

### 5.3 Proposition

Let A ⊆ Ω.

Then:

**1_A is a random variable if and only if A ∈ F.**

### Proof

We prove both directions.

**Direction 1: Suppose 1_A is a random variable.**

We want to show that A ∈ F.

Since 1_A is a random variable:

{1_A > 1/2} ∈ F.

But:

{1_A > 1/2} = A.

Therefore:

A ∈ F.

**Direction 2: Suppose A ∈ F.**

We want to prove that 1_A is a random variable.

Using the random variable criterion, we check whether:

{1_A ≤ t} ∈ F

for every real number t.

Consider three cases.

**Case 1: t < 0**

Since the indicator function takes only the values 0 and 1:

{1_A ≤ t} = ∅.

Since ∅ ∈ F, the condition holds.

**Case 2: 0 ≤ t < 1**

The inequality is satisfied only when 1_A = 0.

Therefore:

{1_A ≤ t} = A′.

Since A ∈ F and sigma-fields are closed under complements:

A′ ∈ F.

**Case 3: t ≥ 1**

Both possible values of the indicator function satisfy the inequality.

Therefore:

{1_A ≤ t} = Ω.

Since Ω ∈ F, the condition holds.

Thus, in all cases:

{1_A ≤ t} ∈ F.

Therefore, 1_A is a random variable.

Hence:

**1_A is a random variable ⇔ A ∈ F.**

### 5.4 Application

Suppose a bank gives a customer a reward of 500 ETB if a particular condition is satisfied.

Let A represent the event that the customer qualifies.

The reward can be represented by:

X = 500 × 1_A.

Therefore:

- If the customer qualifies, X = 500.
- Otherwise, X = 0.

Indicator functions are useful for representing payments, rewards, defaults, and other event-dependent quantities.

## 6. Operations on Random Variables

An important property of random variables is that continuous mathematical operations on them preserve the random-variable property.

### 6.1 Theorem

Let X₁, X₂, ..., Xₙ be random variables.

If f(x₁, x₂, ..., xₙ) is a continuous function, then:

**f(X₁, X₂, ..., Xₙ)**

is also a random variable.

### 6.2 Examples

If X and Y are random variables, then the following are also random variables:

1. X + Y
2. cX, where c ∈ R.
3. XY
4. |X|ᵖ, where p > 0.
5. X/Y, provided Y is nonzero.

For example, if X represents the revenue of one business and Y represents the revenue of another business, then X + Y represents their combined revenue.

### 6.3 Linear Combinations of Indicator Functions

If A₁, A₂, ..., Aₙ belong to F, then:

**X = Σⱼ₌₁ⁿ cⱼ1_Aⱼ**

is a random variable.

This follows because each indicator function is a random variable, and finite linear combinations preserve the random-variable property.

### 6.4 Maximum and Minimum

If X and Y are random variables, then:

- max(X, Y) is a random variable.
- min(X, Y) is a random variable.

These functions identify the larger and smaller values, respectively.

## 7. Cumulative Distribution Function (CDF)

### 7.1 Definition

The cumulative distribution function of a random variable X is defined by:

**F_X(x) = P(X ≤ x), x ∈ R.**

The CDF gives the accumulated probability that X takes a value less than or equal to x.

### 7.2 Example: Two Coin Tosses

Suppose a fair coin is tossed twice.

Let X represent the number of heads.

| x | P(X = x) |
|---|---:|
| 0 | 1/4 |
| 1 | 1/2 |
| 2 | 1/4 |

Calculate the CDF.

**Step 1: Calculate F_X(0).**

F_X(0) = P(X ≤ 0)

= P(X = 0)

= 1/4.

**Step 2: Calculate F_X(1).**

F_X(1) = P(X ≤ 1)

= P(X = 0) + P(X = 1)

= 1/4 + 1/2

= 3/4.

**Step 3: Calculate F_X(2).**

F_X(2) = P(X ≤ 2)

= 1/4 + 1/2 + 1/4

= 1.

Therefore:

**F_X(x) =**

- 0, if x < 0.
- 1/4, if 0 ≤ x < 1.
- 3/4, if 1 ≤ x < 2.
- 1, if x ≥ 2.

### 7.3 Important Properties of a CDF

A CDF has the following properties:

**1. Non-decreasing**

If a ≤ b, then:

F_X(a) ≤ F_X(b).

**2. Limits at infinity**

As x → −∞:

F_X(x) → 0.

As x → +∞:

F_X(x) → 1.

**3. Right-continuity**

The CDF is continuous from the right.

**4. Probability of an interval**

For a < b:

P(a < X ≤ b) = F_X(b) − F_X(a).

### Important Note

The CDF is defined for both discrete and continuous random variables.

## 8. Discrete Random Variables

### 8.1 Definition

A random variable X is discrete if its range is countable.

A countable set can be either finite or countably infinite.

Examples:

- {0, 1, 2, 3}
- {0, 1, 2, 3, ...}

### 8.2 Examples

**Example 1: Number of heads in two coin tosses**

X ∈ {0, 1, 2}.

This is a discrete random variable because its range is finite.

**Example 2: Number of customers entering a bank**

X ∈ {0, 1, 2, 3, ...}.

This is discrete because its range is countably infinite.

**Example 3: Number of loan defaults among 100 customers**

X ∈ {0, 1, 2, ..., 100}.

This is also discrete.

### Main Idea

A discrete random variable takes values from a finite or countably infinite set.

## 9. Probability Mass Function (PMF)

### 9.1 Definition

The probability mass function of a discrete random variable X is defined as:

**p_X(x) = P(X = x).**

It gives the probability that X takes a particular value.

### 9.2 Properties of a PMF

A valid PMF must satisfy:

**1. Non-negativity**

p_X(x) ≥ 0.

**2. Total probability equals one**

Σₓ p_X(x) = 1.

The summation is taken over all possible values of X.

### 9.3 Example

Suppose X represents the number of heads obtained when a fair coin is tossed twice.

| x | p_X(x) |
|---|---:|
| 0 | 1/4 |
| 1 | 1/2 |
| 2 | 1/4 |

Check the total probability:

1/4 + 1/2 + 1/4 = 1.

Therefore, the PMF satisfies the total probability condition.

### 9.4 Calculating Probabilities Using PMF

For any subset A of R:

**P(X ∈ A) = Σₓ∈A p_X(x).**

For example:

P(X ≥ 1)

= P(X = 1) + P(X = 2)

= 1/2 + 1/4

= 3/4.

### 9.5 Relationship Between PMF and CDF

For a discrete random variable:

**F_X(x) = Σᵧ≤ₓ p_X(y).**

This means that the CDF is obtained by adding all PMF values up to x.

Therefore:

- PMF gives the probability of an exact value.
- CDF gives the accumulated probability up to a specified value.

## 10. Important Discrete Probability Distributions

The following five discrete distributions are important:

1. Bernoulli.
2. Binomial.
3. Discrete Uniform.
4. Geometric.
5. Hypergeometric.

### 10.1 Bernoulli Distribution

A Bernoulli random variable represents an experiment with two possible outcomes:

- Success.
- Failure.

Let p be the probability of success.

Then:

P(X = 1) = p.

P(X = 0) = 1 − p.

**Example**

A bank customer either defaults on a loan or does not default.

Let:

X = 1 if the customer defaults.

X = 0 otherwise.

If the probability of default is 0.05:

P(X = 1) = 0.05.

P(X = 0) = 0.95.

**Main idea:** One experiment with two possible outcomes.

### 10.2 Binomial Distribution

A binomial random variable counts the number of successes in a fixed number of independent Bernoulli trials, with constant success probability.

Its PMF is:

**P(X = k) = C(n,k)pᵏ(1 − p)ⁿ⁻ᵏ**

where:

- n = Number of trials.
- k = Number of successes.
- p = Probability of success.
- C(n,k) = Number of ways to select k successes from n trials.

**Example**

Suppose five customers independently have a 10% probability of defaulting.

Let X be the number of defaults.

Then:

X ~ Binomial(5, 0.1).

The probability of exactly two defaults is:

P(X = 2) = C(5,2)(0.1)²(0.9)³

= 10 × 0.01 × 0.729

= 0.0729.

**Main idea:** A fixed number of independent trials, counting the number of successes.

### 10.3 Discrete Uniform Distribution

A discrete random variable is uniformly distributed if all its possible values have equal probabilities.

For a fair six-sided die:

X ∈ {1, 2, 3, 4, 5, 6}.

Each value has probability:

P(X = x) = 1/6.

**Main idea:** Every possible value has the same probability.

### 10.4 Geometric Distribution

A geometric random variable counts the number of independent trials required to obtain the first success.

Its PMF is:

**P(X = k) = (1 − p)ᵏ⁻¹p**

where k = 1, 2, 3, ...

**Example**

Suppose a salesperson has a 20% probability of making a successful sale on each independent attempt.

The probability that the first successful sale occurs on the third attempt is:

P(X = 3) = (0.8)²(0.2)

= 0.128.

**Main idea:** The number of trials required to obtain the first success.

### 10.5 Hypergeometric Distribution

A hypergeometric random variable counts the number of successes in a sample selected without replacement from a finite population.

Its PMF is:

**P(X = k) = [C(K,k)C(N−K,n−k)] / C(N,n)**

where:

- N = Total population size.
- K = Number of successes in the population.
- n = Sample size.
- k = Number of successes in the sample.

**Example**

A company has 10 employees:

- 4 managers.
- 6 ordinary employees.

Three employees are selected without replacement.

Let X be the number of managers selected.

The probability of selecting exactly two managers is:

P(X = 2) = [C(4,2)C(6,1)] / C(10,3)

= (6 × 6)/120

= 0.30.

**Main idea:** Counting successes when sampling without replacement.

### Comparison of Discrete Distributions

| Distribution | Main Idea |
|---|---|
| Bernoulli | One trial with two outcomes |
| Binomial | Number of successes in fixed independent trials |
| Discrete Uniform | All possible values have equal probabilities |
| Geometric | Number of trials until the first success |
| Hypergeometric | Number of successes in sampling without replacement |

## 11. Continuous Random Variables

### 11.1 Definition

A random variable X is continuous if there exists a non-negative, integrable function f_X such that:

**P(X ∈ J) = ∫_J f_X(t)dt**

for every interval J.

The function f_X is called the probability density function.

### 11.2 Understanding Continuous Random Variables

A continuous random variable can take values throughout an interval of real numbers.

Examples include:

- Height of a person.
- Weight of a product.
- Time required to complete a transaction.
- Daily investment returns under a continuous model.

For example, the time required to complete a bank transaction may be:

2 minutes, 2.5 minutes, 2.51 minutes, 2.513 minutes, and so on.

There are uncountably many possible real values in an interval.

### 11.3 An Important Property

For a continuous random variable:

**P(X = a) = 0**

for every individual real number a.

This is because the probability of a continuous random variable is calculated using area under the PDF.

A single point has zero width, so the area is zero.

However, the probability over an interval can be positive:

P(a ≤ X ≤ b) = ∫ₐᵇ f_X(t)dt.

**Important:** Zero probability at an individual point does not mean that the value is impossible.

## 12. Probability Density Function (PDF)

### 12.1 Definition

The probability density function of a continuous random variable X is a non-negative, integrable function f_X satisfying:

**P(X ∈ J) = ∫_J f_X(t)dt.**

### 12.2 Properties of a PDF

A valid PDF must satisfy:

**1. Non-negativity**

f_X(x) ≥ 0.

**2. Total integral equals one**

∫₋∞∞ f_X(x)dx = 1.

### 12.3 Calculating Probabilities

For a continuous random variable:

**P(a ≤ X ≤ b) = ∫ₐᵇ f_X(t)dt.**

The probability is the area under the PDF curve between a and b.

### 12.4 Example

Suppose:

f_X(x) = 1, for 0 ≤ x ≤ 1,

and zero otherwise.

**Step 1: Verify that it is a valid PDF.**

The function is non-negative.

Also:

∫₋∞∞ f_X(x)dx

= ∫₀¹ 1 dx

= 1.

Therefore, it is a valid PDF.

**Step 2: Calculate P(0.2 ≤ X ≤ 0.7).**

P(0.2 ≤ X ≤ 0.7)

= ∫₀.₂⁰.⁷ 1 dx

= 0.7 − 0.2

= 0.5.

Therefore, the required probability is 0.5.

### 12.5 Why Is the Probability at One Point Zero?

For example:

P(X = 0.5) = ∫₀.₅⁰.₅ f_X(t)dt

= 0.

The integration interval has zero width, so its area is zero.

**Main idea:** A PDF describes the density of probability. Probability is obtained by integrating the density over an interval.

## 13. Relationship Between PDF and CDF

For a continuous random variable:

**F_X(x) = P(X ≤ x) = ∫₋∞ˣ f_X(t)dt.**

This formula establishes the relationship between the PDF and CDF.

The CDF is obtained by integrating the PDF from negative infinity up to x.

Conversely, if the CDF is differentiable at x:

**f_X(x) = F′_X(x).**

Therefore:

- Integrating the PDF gives the CDF.
- Differentiating the CDF gives the PDF, wherever the derivative exists.

### Example

Suppose:

f_X(x) = 2x, for 0 ≤ x ≤ 1,

and zero otherwise.

Find the CDF.

**Case 1: x < 0**

F_X(x) = 0.

**Case 2: 0 ≤ x ≤ 1**

F_X(x) = ∫₀ˣ 2t dt

= [t²]₀ˣ

= x².

**Case 3: x > 1**

F_X(x) = 1.

Therefore:

**F_X(x) =**

- 0, if x < 0.
- x², if 0 ≤ x ≤ 1.
- 1, if x > 1.

### Another Example: Finding the PDF from the CDF

Suppose:

F_X(x) = x², for 0 ≤ x ≤ 1.

Differentiating:

f_X(x) = F′_X(x)

= 2x.

Therefore:

f_X(x) = 2x, for 0 ≤ x ≤ 1.

## 14. Important Continuous Probability Distributions

Three important continuous distributions are:

1. Uniform Continuous.
2. Normal.
3. Exponential.

### 14.1 Uniform Continuous Distribution

A continuous random variable is uniformly distributed over [a, b] if its PDF is constant throughout the interval.

Its PDF is:

**f_X(x) =**

- 1/(b − a), if a ≤ x ≤ b.
- 0, otherwise.

**Example**

Suppose a bus arrives uniformly between 10:00 and 10:30.

Let X represent the number of minutes after 10:00 when the bus arrives.

Then:

X ~ Uniform(0, 30).

The probability that the bus arrives between 10 and 20 minutes is:

P(10 ≤ X ≤ 20)

= (20 − 10)/(30 − 0)

= 1/3.

**Main idea:** Equal-length intervals have equal probabilities.

### 14.2 Normal Distribution

The normal distribution is a widely used continuous probability distribution.

Its PDF is:

**f_X(x) = [1/(σ√(2π))] exp[−(x − μ)²/(2σ²)]**

where:

- μ = Mean.
- σ = Standard deviation.
- σ² = Variance.

We write:

**X ~ N(μ, σ²).**

Important properties:

1. The normal distribution is symmetric around its mean.
2. Mean = Median = Mode.
3. The total area under the curve equals one.
4. The mean determines the center.
5. The standard deviation determines the spread.

**Example**

Suppose examination scores approximately follow:

X ~ N(70, 100).

Then:

- Mean = 70.
- Variance = 100.
- Standard deviation = 10.

The distribution is centered around 70.

**Main idea:** The normal distribution represents a symmetric, bell-shaped probability distribution.

### 14.3 Exponential Distribution

The exponential distribution is commonly used to model waiting times.

Its PDF is:

**f_X(x) =**

- λe^(−λx), if x ≥ 0.
- 0, otherwise.

where λ > 0 is the rate parameter.

**Example**

Suppose the time between customer arrivals at a bank follows an exponential distribution.

If the average waiting time between arrivals is 5 minutes:

Mean = 1/λ.

Therefore:

λ = 1/5 = 0.2.

The waiting time can be modeled as:

X ~ Exponential(0.2).

**Main idea:** The exponential distribution models non-negative waiting times.

## 15. Comparison of Discrete and Continuous Random Variables

| Feature | Discrete Random Variable | Continuous Random Variable |
|---|---|---|
| Possible values | Finite or countably infinite | Values over continuous intervals |
| Probability function | PMF | PDF |
| Probability at an exact value | Can be positive | Always zero |
| Probability calculation | Summation | Integration |
| Total probability | Sum of PMF = 1 | Integral of PDF = 1 |
| CDF | Sum of PMF values up to x | Integral of PDF up to x |
| Example | Number of customers | Waiting time |

### Important Distinction

Suppose X represents the number of customers entering a bank.

We can calculate:

P(X = 5).

However, if Y represents the waiting time of a customer, modeled as continuous, then:

P(Y = 5) = 0.

Instead, we calculate:

P(5 ≤ Y ≤ 10).

This is because continuous probabilities are calculated over intervals.

## 16. Common Mistakes

1. **Confusing outcomes with random variables.**

   Outcomes belong to the sample space Ω, while a random variable is a function that assigns numerical values to those outcomes.

2. **Confusing the sample space with the sigma-field.**

   Ω contains outcomes, whereas F contains measurable subsets of Ω.

3. **Thinking that every real-valued function is automatically a random variable.**

   A random variable must satisfy the measurability condition.

4. **Confusing PMF and CDF.**

   PMF gives the probability of an exact value, whereas CDF gives accumulated probability up to a specified value.

5. **Confusing PDF with probability.**

   PDF represents density. Probability is obtained by integrating the PDF over an interval.

6. **Forgetting that the CDF is defined for both discrete and continuous random variables.**

7. **Thinking that P(X = a) = 0 means that a is impossible for a continuous random variable.**

   Zero probability at an individual point does not mean impossibility.

8. **Forgetting the conditions of a valid PDF or PMF.**

   Both must be non-negative and have total probability equal to one, using summation for PMFs and integration for PDFs.

a. Find the range of X.

### Question 2: Indicator Functions

### Question 8: Conceptual Understanding

**a. PMF vs. PDF**

PMF gives the probability of an exact value of a discrete random variable. PDF describes the density of probability for a continuous random variable.

**b. PMF vs. CDF**

PMF gives P(X = x), while CDF gives P(X ≤ x).

**c. Discrete vs. Continuous Random Variables**

A discrete random variable has a finite or countably infinite range. A continuous random variable has probabilities over intervals represented by integrating a density function.

**d. PDF vs. CDF**

PDF describes probability density, whereas CDF describes accumulated probability.
